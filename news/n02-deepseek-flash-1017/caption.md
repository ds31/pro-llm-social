DeepSeek дообучил Flash под собственную обвязку для агентов — и до 1 ноября её можно гонять бесплатно.

17 октября вышла Flash 1017 — минорное обновление V4.1 Flash. Веса на Hugging Face под MIT, контекст 1M токенов. Имя в API не поменялось: сидите на deepseek-flash — вы уже на 1017. Цена API — $0,30 / $1,20 за 1M токенов на вход / выход.

По данным самого DeepSeek: DeepSWE 74,2 → 77,0, ProgramBench 20,3 → 29,1. Terminal-Bench 4.0 вырос с 31,2 до 42,3, но новую цифру сняли в Claude Code, а не в собственной обвязке — яблоко с грушей.

Что это значит для того, кто внедряет: бесплатное окно до 1 ноября (по данным на 21.10) — повод замерить одну модель в двух обвязках на своих задачах. Обновить DeepSeek Harness до 0.2.1-rc.1 или новее и прогнать одну рабочую задачу через dsh и через Claude Code.

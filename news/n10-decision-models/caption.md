Модель, которая не пишет текст, а возвращает решение с вероятностью. За месяц в эту категорию зашли OpenAI, Perplexity, Cloudflare и AWS.

15 сентября TypeSafe выпустила Jev. 29 сентября OpenAI показала на DevDay свой Decisions API, 1 октября Perplexity открыла API на собственной открытой модели, в тот же день свои модели выпустили AWS и Cloudflare. 6 октября OpenAI открыла Decisions API всем в бете.

Принцип у всех один: выход бесплатный, платите только за вход. Perplexity Decider — $0,02 за 1M входных токенов, открытые веса под Apache 2.0. Jev — $0,042, OpenAI — $0,10. Perplexity заявляет 85,71 % против 84,51 % у Jev, но это её собственный набор тестов.

Что это значит для того, кто внедряет: для разметки отзывов, маршрутизации тикетов и модерации появился отдельный класс моделей. Возьмите одну задачу, где сейчас LLM ставит метку, прогоните 200–300 примеров через Decider и сравните с текущим решением по точности, скорости и цене.

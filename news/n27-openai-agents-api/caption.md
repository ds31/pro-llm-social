OpenAI выпустила Agents API — и это важнее, чем ещё одна новая модель.

10 сентября OpenAI открыла public beta Agents API. Раньше через API брали модель: отправил текст — получил ответ. Всё, что превращает модель в агента — цикл шагов, вызовы инструментов, память, восстановление после ошибок, запуск кода в песочнице, — команды писали сами. Теперь OpenAI отдаёт этот слой готовым: ту же обвязку (harness), что работает внутри Codex.

Агент может работать в песочнице OpenAI или в вашей инфраструктуре. Теоретически данные и запуск кода можно оставить в своём VPC, а OpenAI использовать только для управления шагами.

Что это значит для того, кто внедряет: качество агента теперь решает не только модель, но и обвязка. Проверьте Agents API на длинной задаче, а не на чат-боте, и сравните со своей обвязкой по доле успешных задач, стоимости, ручным повторам, стабильности и работе с контекстом.

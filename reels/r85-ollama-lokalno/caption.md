Нейросеть на своём компьютере — одной командой: ollama run gemma4:e2b

Ollama — открытая программа (лицензия MIT, 185,1 тыс. звёзд на GitHub), которая запускает открытые модели у вас на компьютере. Скачиваете её для macOS, Windows или Linux, пишете в терминале ollama run gemma4:e2b — Ollama сама скачает модель и откроет чат. Выйти — /bye.

Сколько нужно памяти: для Gemma 4 E2B документация советует 8 ГБ свободной видеопамяти (на Mac — общей памяти). Меньше — Ollama возьмёт обычную оперативную память, но ответы будут медленнее. У самой Ollama лицензия MIT, у модели своя — у Gemma 4 E2B Apache 2.0.

Куда уходят данные: по FAQ Ollama, при локальном запуске компания не видит ваши запросы и данные. Но есть и облачные модели (например, gemma4:cloud) — их запросы обрабатывает сервер. Только локально: OLLAMA_NO_CLOUD=1.

Что это значит для того, кто внедряет: прототип на чувствительных данных можно собрать локально, ничего не отправляя во внешний API.
